# 재무지표 비교

국내(KOSPI·KOSDAQ)와 미국(NYSE·NASDAQ) 상장기업의 장기 재무지표를 한 화면에서 겹쳐 봅니다.
공시 원문 — 금융감독원 DART, SEC EDGAR — 에서 직접 가져오고, 계산 근거를 화면에 함께 보여줍니다.

```
삼성전자 · Intel · NVIDIA 를 골라 2015~2025 영업이익률과 PER 추이를 한 번에 본다
```

**본인 컴퓨터에서 돌리는 도구입니다.** 웹서비스가 아니라 각자 설치해서 씁니다.
받아온 데이터는 본인 컴퓨터의 SQLite 파일에만 쌓이고, API 키는 밖으로 나가지 않습니다.

## 설치

Node.js 20 이상이 필요합니다. 없으면 [nodejs.org](https://nodejs.org)에서 LTS를 받으세요.

```bash
git clone https://github.com/hi-suhyun/fincompare.git
cd fincompare
./setup.sh
```

`setup.sh`가 필요한 키를 하나씩 물어보며 `.env`를 만들고, 기업 목록과 국내 주가까지 받아옵니다.
이미 `.env`가 있으면 비어 있는 항목만 채웁니다 — 기존 키는 건드리지 않습니다.

실행:

```bash
./start.sh
```

`http://localhost:5173`이 열립니다. 그 터미널 창을 열어둔 채로 쓰세요.

### 필요한 키

| | 어디서 | 비용 | 없으면 |
|---|---|---|---|
| `DART_API_KEY` | [opendart.fss.or.kr](https://opendart.fss.or.kr/) | 무료·즉시 | **국내 기업 조회 불가** |
| `SEC_USER_AGENT` | 발급 없음. 이메일만 넣으면 됨 | — | **미국 기업 403** |
| `KRX_AUTH_KEY` | [openapi.krx.co.kr](https://openapi.krx.co.kr/) | 무료·승인 필요 | 국내 주가·PER·PBR 없음 |
| `TIINGO_API_KEY` | [tiingo.com](https://www.tiingo.com/) | 무료 | 미국 주가·PER·PBR 없음 |
| `FMP_API_KEY` | [financialmodelingprep.com](https://site.financialmodelingprep.com/) | 무료 250콜/일 | 애널리스트 추정 밴드 없음 |

앞의 둘만 있어도 재무지표는 전부 동작합니다. 나머지는 있으면 좋은 것들입니다.

> **KRX 주의** — 인증키 승인과 API 이용신청은 **별개 절차**입니다. 키만 받으면 모든 호출이 401입니다.
> 「서비스 이용 > 주식」에서 *유가증권 일별매매정보*와 *코스닥 일별매매정보* 각각에 「API 이용신청」을
> 눌러야 하고, 마이페이지 > 이용현황에서 "승인"으로 바뀌어야 동작합니다.

### 왜 로컬 전용인가

무료 금융 API는 예외 없이 재배포를 막습니다. Tiingo는 "받은 데이터를 다른 사람에게
보여주거나 공유하지 말 것"을, FMP는 한발 더 나아가 "제3자가 접근 가능한 도구에 통합하는
것" 자체를 금지합니다.

경계는 **데이터**에 있지 **코드**에 있지 않습니다:

| | |
|---|---|
| ❌ 내 키로 띄운 서버 링크를 남에게 주고, 그 사람이 데이터를 본다 | 내가 데이터를 재배포하는 것 |
| ✅ 각자 자기 키로 자기 컴퓨터에서 본다 | 제공처에서 본인에게 직접 간 본인 데이터 |

그래서 웹서비스로 만들면 미국 PER·PBR과 애널리스트 컨센서스를 **뺄 수밖에** 없습니다.
로컬 전용으로 가면 그 제약이 통째로 사라져서, **모든 기능이 모든 사용자에게 열립니다.**

## 무엇이 다른가

- **이중 Y축을 쓰지 않습니다.** 지표마다 차트를 따로 두고 세로로 쌓습니다. 축 눈금을 픽셀 단위로 맞춰
  어느 차트의 2019년이든 같은 가로 위치에 옵니다. 한 곳에 마우스를 올리면 모든 차트에 세로선이 함께 서고,
  그 해의 모든 기업 × 모든 지표 값이 한 번에 읽힙니다.
- **빈 데이터를 0으로 채우지 않습니다.** 값이 없으면 선을 끊고 **왜 없는지** 설명합니다 —
  회사가 그 항목을 공시하지 않았는지, 주가를 연동하지 않았는지, 적자라 PER이 성립하지 않는지.
- **회계 기준을 맞춥니다.** K-IFRS와 US GAAP 계정을 매핑하고, 결산월이 다른 기업(예: NVIDIA 1월,
  Microsoft 6월)을 SEC가 쓰는 것과 같은 규칙으로 같은 연도에 정렬합니다.
- **액면분할에서 선이 끊기지 않습니다.** 주당 지표(EPS · BPS · 주가)는 분할 이전 구간을
  분할 후 기준으로 환산합니다. 삼성전자 2018년 50:1 분할에서 EPS가 299,868원에서 6,461원으로
  떨어져 이익이 98% 증발한 것처럼 보이는 일이 없습니다. PER · PBR은 분자와 분모가 같은 계수로
  나뉘어 조정 여부와 **완전히 같은 값**이고, 각 시점 공시값이 필요하면 토글로 끕니다.

설계 판단의 근거는 [docs/](docs/)에 있습니다 — [데이터 소스 비교](docs/00-data-sources.md),
[계정 매핑](docs/01-account-mapping.md), [아키텍처](docs/02-architecture.md),
[사용자 맥락](docs/03-user-context.md).

## 데이터 미리 받아두기

처음 조회하는 기업은 공시에서 받아오느라 몇 초 걸립니다. 자주 볼 기업을 미리 받아두면
그 뒤로는 즉시 나옵니다.

```bash
# 국내 전 종목 주가·시가총액 (22번 호출, 15초)
pnpm --filter @fincompare/api backfill:kr-prices

# 국내 시가총액 상위 300개 재무데이터
pnpm --filter @fincompare/api backfill:kr

# 미국 주요 64개 재무데이터 (33초)
pnpm --filter @fincompare/api backfill:us
```

`backfill:kr`은 시가총액 순으로 채웁니다 — 그 순위는 `backfill:kr-prices`가 KRX에서 받아온
값이라, 주가를 먼저 받아야 합니다. 개수는 `--top 100`처럼 바꿀 수 있습니다.

DART는 SEC와 달리 **기업×연도마다** 호출해야 해서 300개면 약 3,300회입니다
(일일 한도 19,000의 17%). 전체 2,596개를 다 받으려면 이틀에 나눠 돌려야 합니다.

## 애널리스트 컨센서스

미국 기업의 연도별 **추정치 범위**(최고·평균·최저)를 띠로 겹쳐 봅니다.
실선(실제 공시값)이 띠 안에 있으면 그 해 추정이 맞았다는 뜻입니다.

### 쓰는 법

1. 미국 기업을 고릅니다 (엔비디아, 애플 등)
2. 지표에서 **「매출액」이나 「EPS」**를 고릅니다
3. **「애널리스트 컨센서스」** 토글을 켭니다

**밴드는 매출액·EPS 에만 붙습니다.** 영업이익이나 주가를 보고 있으면 아무것도
그려지지 않습니다 — FMP 가 그 두 지표만 추정치를 주기 때문입니다. 그럴 때는
화면이 이유를 알려줍니다.

이런 경우에도 밴드가 안 보입니다:

| 상황 | 이유 |
|---|---|
| 국내 기업 | 컨센서스를 제공하지 않습니다 (아래 참고) |
| 「표시 통화」가 원화 | 추정치는 달러 기준이라 실제값만 환산되면 어긋납니다 |
| 「한 차트에 겹쳐 보기」 | 지수 축이라 추정치의 절대값이 의미를 잃습니다 |
| 「분기」 보기 | 추정치가 연간 단위입니다 |
| `FMP_API_KEY` 없음 | 토글이 비활성화되고 이유가 표시됩니다 |

### 읽는 법

엔비디아 EPS로 보면:

| 연도 | 추정 평균 | 실제 | 실제/추정 |
|---|---|---|---|
| 2022 | 0.33 | 0.18 | **0.54** — 암호화폐 폭락, 2배 가까이 높게 봄 |
| 2023 | 1.24 | 1.21 | 0.97 |
| 2025 | 4.69 | 4.93 | 1.05 |

추정치는 회계기간 종료일을 그대로 받아 실제값과 **같은 정렬 규칙**을 태웁니다.
연도만 잘라 쓰면 1월 결산인 엔비디아의 추정치가 한 해 뒤로 밀립니다.

**현재 목표주가**는 밴드와 별개로 안내문에 함께 표시됩니다 (예: 218~500, 평균 319.48).
발행일이 붙은 개별 목표주가는 FMP 유료 구간이고 구버전 엔드포인트는 2025-08-31자로
폐지돼서, "그때 맞았나"는 목표주가가 아니라 추정치로 답합니다.

추정치도 목표주가도 예측이 아니라 애널리스트의 **의견**입니다. 화면에도 그렇게 적어 둡니다.

**국내 기업은 컨센서스를 제공하지 않습니다.** 증권사 리포트는 저작물이라 가져와 저장하지
않고, 차트에 마우스를 올리면 뜨는 툴팁에서 **그 시점 리포트**로 나가는 링크만 놓습니다.

## 구조

```
packages/shared    지표 정의, 계정 매핑, 회계연도 정렬, 색상 팔레트
apps/api           Express. 외부 API 호출·캐싱·계산. 키는 여기서만 읽는다
apps/web           Vite + React + Recharts
setup.sh           최초 설치 (키 입력 + 데이터 준비)
start.sh           실행
```

프론트는 외부 API를 직접 부르지 않습니다 — 키가 노출되고 캐싱도 안 되기 때문입니다.
외부 응답은 전부 Zod로 검증한 뒤 어댑터에서 내부 형식으로 변환합니다.

```bash
pnpm test        # 전체 테스트
pnpm typecheck   # 타입 검사
```

## 문제가 생기면

**`ERR_CONNECTION_REFUSED`** — 서버가 꺼졌습니다. `./start.sh`를 실행하고 그 창을 열어두세요.

**국내 기업이 "데이터 없음"** — `DART_API_KEY`를 확인하세요. `.env`에 있는지, 40자리가 맞는지.

**국내 PER·PBR만 없음** — KRX 키는 발급과 **이용신청이 따로**입니다. 위 주의사항을 보세요.

**처음 조회가 느림** — 공시에서 받아오는 중입니다. 한 번 받으면 그 뒤로는 즉시 나옵니다.
미리 받아두려면 위의 백필 명령을 쓰세요.

**데이터를 처음부터 다시 받고 싶을 때** — `apps/api/data/dev.db`를 지우고 `./setup.sh`를
다시 실행하세요.

## 출처

재무제표는 금융감독원 DART와 SEC EDGAR의 각 연도 사업보고서 공시값입니다.
국내 주가는 한국거래소(KRX) 일별매매정보의 실거래 종가, 환율은 ECB입니다.
내부 계산은 미조정 종가와 각 시점 공시 EPS를 짝지어 PER을 구하고, 화면 표시 단계에서
액면분할을 조정합니다 — 비율이 보존되므로 두 기준의 PER은 같습니다.

투자 판단의 근거로 쓰기 전에 원문 공시를 확인하세요.
